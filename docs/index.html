local-volatility

A four-language reference implementation (Python normative, C++, Rust, Java) of the full local-volatility pricing pipeline: an implied-volatility surface in total-variance form, Dupire local volatility in Gatheral's formula, a Crank-Nicolson/Rannacher finite-difference pricer with a PSOR American-put variant, and a log-Euler Monte Carlo engine with a Brownian-bridge barrier correction. Every port is held to the same 15 golden cases and to a round-trip check — SSVI surface → Dupire → PDE → implied vol — that recovers the surface to 2.73 bp with zero clamps; API_SPEC.md pins the spline, Thomas solver, wing clamp, Rannacher schedule and upwind rule so deterministic engines match to tight absolute tolerances.

What the latest review found and fixed. The Dupire finite-difference stencil was allowed to straddle the flat-wing kink of the implied surface, which produced 500 % local vols at the last quoted strike and a round-trip implied-vol error of 16.4 bp, about 85 % of it caused by those spikes. The stencil is now clamped to [k_min + DK, k_max − DK]; the round-trip error fell to 2.73 bp with zero clamps, so on a smooth input surface any non-zero clamp counter now means genuine arbitrage. The same review defined vol(k, 0) as the Berestycki-Busca-Florent short-time limit instead of an undefined division, added first-order upwinding at Péclet-violating nodes (M-matrix preserved), checked user vol callables for NaN/negative output, made the CSV loader strict, moved pillar goldens 1e-3 off the pillars and regenerated golden.json; all three native ports were re-pinned. Not verified: behaviour on real, noisy market quotes — the bundled surface is a smooth SSVI sample.

What's inside

Implied-volatility surface

ImpliedVolSurface stores total variance w(k, T) on forward log-moneyness: a natural cubic spline per expiry, linear total variance in T, flat wings, flat-forward-variance below the first pillar and floored-slope linear extrapolation beyond the last. A calendar-arbitrage node check and a spline-overshoot (w ≤ 0) scan run at build time; violations are counted and warned, never repaired or raised.

Dupire local volatility

Gatheral's total-variance form of the Dupire formula with fixed-step central finite differences (DK = 1e-3, DT = 1e-4), the stencil clamped inside the quoted strike box, T = 0 defined as the Berestycki-Busca-Florent short-time limit, and output clamped to [1 %, 500 %] with thread-safe floor/cap counters (atomics in C++/Rust, LongAdder in Java) so one DupireLocalVol can be shared across threads.

Finite-difference pricer

Log-spot theta scheme: Crank-Nicolson with a Rannacher start of two backward-Euler half-steps, a native Thomas tridiagonal solver, Dirichlet boundaries from discounted asymptotics, the price read at the exact spot node, and a first-order upwind fallback at any node violating the mesh Péclet condition. American puts use projected SOR on the same systems (omega = 1.5, tol = 1e-8, warm-started); non-convergence warns, never throws.

Monte Carlo & barriers

Log-Euler with start-of-step local-vol lookup, antithetic pairs with a pair-mean standard error, fixed seeds per language (NumPy PCG64, std::mt19937_64, Rust StdRng, Java L64X128MixRandom), and user vol callables checked for finite non-negative output. Up-and-out calls use discrete monitoring plus optional Brownian-bridge survival weights that remove the O(√dt) monitoring bias.

Black-Scholes / Garman-Kohlhagen

Price, delta, gamma, vega and a bisection implied-vol inverter (100 halvings on [1e-9, 5]) that rejects prices outside the static no-arbitrage bounds. Equity (r, q) and FX (rd, rf) share every formula through one Market type; the surface is carry-free and the pricers reintroduce carry.

Golden suite & generator

data/golden/golden.json holds 15 cases; each language dispatches on the case-name prefix and asserts |got − expect| ≤ tol. References are exact identities (flat Dupire = 0.20), closed forms (Black-Scholes, Reiner-Rubinstein barrier), CRR-5000 binomial for the American put, and the Python reference for local-vol cases. generate_data.py validates against Black-Scholes, the flat-surface identity and a no-clamp sweep before writing.

Validation & error contract

NaN/inf/negative/empty/unsorted/duplicate inputs are rejected at every public entry point with the idiomatic error (ValueError, std::invalid_argument, Err(LocalVolError), IllegalArgumentException); bounds such as num_space even and ≥ 4, omega ∈ (0, 2), n_paths ≥ 4 with antithetics are pinned. Reported rather than raised: calendar arbitrage, spline overshoot, Dupire clamps, PSOR non-convergence, single-expiry surfaces.

Units, scope, limits

Spot is a price or FX rate, rates are continuously compounded, T is a bare year fraction — no day count, calendar, settlement lag or date type. Continuous yield only; single flat r and q per call; European calls/puts, American puts and continuously-monitored up-and-out calls; no calibration, the surface is taken as given. Local vol is discontinuous in T at each pillar, the PDE grid is uniform, and Greeks at the kink retain an O(dt) component from the two-half-step Rannacher start.

Quick start

git clone https://github.com/AshJha0/local-volatility && cd local-volatility

# Python reference (3.11, numpy >= 1.24, pytest)
cd python
PYTHONPATH=src python3 -m pytest -q    # test suite (incl. golden cases): 90 passed
PYTHONPATH=src python3 demo.py         # round-trip demo
cd ..

# C++ (C++17, CMake >= 3.16, GoogleTest, g++ 13)
cd cpp
bash build.sh    # cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j2
ctest --test-dir build --output-on-failure   # 72 tests
./build/demo
cd ..

# Rust (edition 2021)
cd rust
cargo build --release      # zero warnings
cargo test --release       # 73 tests
cargo run --release --bin demo
cd ..

# Java (21, JUnit 4 — no Maven/Gradle)
cd java
bash build.sh    # javac -Xlint:all everything into out/ (zero warnings)
bash test.sh     # JUnitCore on all *Test classes: 70 tests
bash demo.sh     # runs the demo main (data dir defaults to ../data)
